# GitHub Repository Inventory & Auditor

Daily inventory of every repository in our GitHub Enterprise Cloud org: repositories, branches, branch protection, access (who has permission and why), CODEOWNERS, and GitHub Actions usage. The data is stored in PostgreSQL and reported through Metabase, and later a custom web app.

## Quick start (local, Windows PowerShell)
```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install --require-hashes -r requirements-dev.txt
pip install --no-deps -e .
copy .env.example .env          # fill in GitHub App + DB settings
docker compose up -d db
auditor check-config
pytest
```

## Dependencies
Versions are never hand-pinned. `pyproject.toml` lists package names. `requirements.txt` (runtime) and `requirements-dev.txt` (dev) are **generated by `pip-compile`** with hashes, and checked with **`pip-audit`**.

```powershell
.\scripts\lock.ps1              # re-resolve to latest + vulnerability scan
pip-sync requirements-dev.txt   # make the venv match the lock exactly
pip install --no-deps -e .
```
CI re-runs `pip-audit` on every PR and weekly. Dependabot opens weekly update PRs.

## Layout
```
docs/               design docs
src/auditor/        Python package (collector, CLI)
tests/              pytest suite
scripts/            dev helpers (lock.ps1)
db/migrations/      numbered SQL migrations (tables in schema `inventory`), run by `auditor db migrate`
db/views/           report views (schema `reporting`), rebuilt on every upgrade
infra/terraform/    AWS infrastructure (Phase 4)
api/, web/          custom web app (Phase 6)
```
